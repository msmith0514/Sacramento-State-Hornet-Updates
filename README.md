# Sac State Baseball Daily — Former Hornets

Static GitHub Pages site focused only on former Sacramento State baseball players.

## New in this version
- 14 individual player profiles under `/players/<player-name>/`
- 2026 professional season-stat snapshot
- Sacramento State career-stat block
- MLB/MiLB/NPB career-stat block where available
- College awards and professional awards/milestones
- Official source links on every profile

Stats are a snapshot dated August 18, 2026. Because GitHub Pages is static, update `data.js` to refresh values or add a scheduled GitHub Action/API workflow later.

## Publish
Upload the contents of this folder to the repository root and use GitHub Pages → Deploy from branch → `main` → `/ (root)`.
