# Sac State Baseball Daily — v14

GitHub Pages-ready static site focused only on former Sacramento State baseball players.

## v14 changes
- Removes the explanatory copy about why featured Player/Pitcher of the Day information has not changed.

- Each tracked former Hornet now has a dedicated feature-story page under `articles/<player>/`.
- Feature stories use the verified statistical snapshot and Sacramento State/pro career information already stored in the site data.
- Keeps the MLB and Division I scoreboards from v13.
